# Templates

- `BRIEF.md`: stage 1. Copy it to your HyperFrames project root.
- `STORYBOARD.md`: stage 4. One block per frame.
- Theme sheet: [`docs/themes/_template.html`](../docs/themes/_template.html) is the shared chrome for a four-cell mini storyboard. Copy it to design a new theme, then add a `docs/themes/data/NNN.json` entry and run `python tools/build_gallery.py`.
