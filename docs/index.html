Every sheet below tells the same 45-second story about the same fictional product, Acme Pulse, in a different visual theme. Each one has four key frames, a six-part component kit, three motion techniques and notes on how to adapt it to your own product. Pick one and hand it to Claude Code with HyperFrames.
