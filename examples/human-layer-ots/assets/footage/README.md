# assets/footage

This folder is git-ignored, apart from this file. It fills up with:

- `placeholders.py` output: `s01-ots.mp4`, `s02-tap.mp4` and `s03-face.mp4` as stand-ins, or
- `tools/fal_shots.py shots.json` output: `cast.png`, the stills, the clips and `fal-results.json` (the cache of fal URLs), and
- `tools/screen_track.py` output: `s01-screen.js`, the screen corners the composition loads.

Generated people stay on your machine. The repository keeps only the recipe (`shots.json`).
