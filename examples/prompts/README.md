# Prompt examples

Real prompts that produced finished films with this kit. Each file has the prompt as it was used, the same prompt as a fill-in template, and what happened at each gate.

| Prompt | Film |
|---|---|
| [mascot-product-promo.md](mascot-product-promo.md) | 1:1 LinkedIn, 35 s: an original mascot looks for its brand in AI answers (made from a public product page, used as an unofficial example) |

Every prompt starts with `/saas-motion-video`, so the skill runs the seven stages and the creative pass. Paste one, swap in your product URL and your assets, and stop at each gate to decide.
